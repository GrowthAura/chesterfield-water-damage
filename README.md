# Water Damage Restoration Chesterfield MO

Water Damage Restoration Chesterfield, MO — 24/7 emergency water damage restoration.
Next.js 14 static export (Tulsa 1 theme, converted to JS). Homepage + 16 service pages.

## Local development

```bash
npm install
npm run dev
```

## Build (static export)

```bash
npm run export
```

Output goes to `out/`. Served locally with `python3 serve.py` (port 8124).

## Deploy

`main` = source only. `gh-pages` = built site (GitHub Pages, subpath-prefixed).
